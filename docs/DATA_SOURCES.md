# ORRERY — Data Sources & Provenance (PLAN §13)

All science data is **bundled at compile time**; the app runs fully offline (R6).
Every generated file records its fetch tool, endpoint and date.

## Accuracy ceilings stated in-app (UI footer + residual panel)

- **Inner planets, Earth/EMB:** ≤0.12″ vs Horizons at the frozen epochs (cap 1″).
- **Jupiter/Saturn:** ≤0.48″ (cap 1″).
- **Uranus/Neptune:** ≤2.4″ — VSOP87 is a fit to DE200; the modern DE differs at the
  arcsecond level for the outer planets. Documented, capped at 2.5″ in tests.
- **Pluto:** arc-minute class (JPL approximate table), validated 1800–2050 AD only;
  the 2100 test epoch is skipped by the harness.
- **Moons:** mean-circle, arc-minute class (ADR-004); timing correct.
- **Exoplanets:** two-body from published elements; uncertainties displayed (§5.2).
  No moons/asteroids/comets claimed for exo systems.

## Online layer (R15)

Event-driven only (user TEST/REFRESH), never per-frame. Endpoints:
Horizons (keyless), Exoplanet Archive TAP (keyless), `api.nasa.gov/neo` (**keyed**).
All gated by the sliding-window CPM limiter (`rate_limiter.rs`, ADR-007).
`LINK = OFF` ⇒ zero network calls; R1–R13 remain fully satisfied offline.
